# Продуктовые требования (скелет)

## Роли ассистента

1. Видеть чаты, куда добавлен бот; отслеживать join/leave бота.
2. Архивировать новые сообщения.
3. Давать короткие сводки по чатам и проектам.
4. Работать из **управляющей группы**; команды по всем чатам — только для ролей owner/admin/manager.
5. Напоминать о своевременных ответах клиентам (SLA), без спама и с рабочими часами/mute.
6. Задачи и проекты; не угадывать проект молча — запрашивать подтверждение.
7. База знаний (PDF/DOCX/MD/ссылки и т.д.) через RAG, ответы с источниками.
8. «Самообучение» = сохранение **правил** в Studio DB с аудитом, не правка кода.

## Ограничения

- Один бот; без второго бота и без Telegram App на первом этапе.
- Системные статусы только в управляющую группу или только лог, если группа не задана.
- Write-операции с правами и аудитом; идемпотентность по `update_id`.
- Response Queue: последовательность внутри чата, параллель между чатами, debounce, статусы turn, не терять сообщения.
