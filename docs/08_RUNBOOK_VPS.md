# Runbook: VPS / продакшен (подготовка)

## Домен

- Целевой домен: **memo.pb-web.ru** (из `DOMAIN` в `.env.example`).

## Состав (план)

- **Caddy** — TLS и reverse proxy к Memoh и Studio API.
- **docker-compose.prod.yml** — скелет в репозитории; полная сборка — ближе к Фазе 14.
- Сервисы: memoh (как в upstream), studio-api, studio-worker, studio-beat, postgres, redis.

## Деплой

- **Без явного подтверждения пользователя и без доступов к VPS агент продакшен не деплоит.**
- Сборка артефактов — локально или в CI; на сервер переносятся готовые образы/файлы (не собирать тяжёлые вещи на VPS без необходимости).

## Порты (черновик)

- 80/443 — Caddy.
- Внутренние порты сервисов — только в docker network; наружу минимум поверхностей.

## Backup / восстановление

- Регулярный дамп Postgres (pg_dump) и копия томов — описать в этом файле после финализации compose (Фаза 14).
- Хранить бэкапы вне сервера; тестировать восстановление на копии.
