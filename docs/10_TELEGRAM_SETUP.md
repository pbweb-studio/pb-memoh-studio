# Настройка Telegram (для владельца студии)

## 1. Создать бота

1. Откройте [@BotFather](https://t.me/BotFather).
2. Команда `/newbot`, имя и username бота.
3. Скопируйте **токен** и вставьте в `.env.local` как `TELEGRAM_BOT_TOKEN=...`.

## 2. Privacy mode (группы)

Если бот должен **видеть все сообщения** в группах (а не только команды и упоминания):

- В BotFather: `/mybots` → ваш бот → **Bot Settings** → **Group Privacy** → **Turn off** (Disable).

Иначе в группах бот часто не увидит обычные реплики.

## 3. Тестовая группа

1. Создайте тестовую группу.
2. Добавьте бота в группу.
3. Напишите тестовое сообщение (после отключения privacy — от имени участников).

## 4. Управляющая группа

1. Создайте отдельную группу для операторов студии.
2. Добавьте туда бота.
3. Назначьте её **управляющей** через Studio Admin или команду (появится в следующих фазах).

## 5. Системные сообщения

- **Запрещено** слать системные уведомления («бот добавлен», «бот удалён», статусы инфраструктуры) в клиентские или рабочие чаты, куда бота просто добавили.
- **Разрешено** только в **управляющую группу**.
- Если управляющая группа **ещё не настроена** — события **только логируются** в Studio Layer, в Telegram **ничего не шлём**.

## 6. Один бот

Не создавайте второго бота для той же роли: все сценарии студии идут через одного.
