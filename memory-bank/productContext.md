# Product context

**Для кого:** небольшая студия, нужен «младший операционный менеджер» в Telegram.

**Зачем:** единая точка входа в чатах: архив, дайджесты, контроль ответов клиентам, знания, задачи — без множества ботов и без того, чтобы владелец держал архитектуру в голове.

**Ключевые ожидания:** один бот, управляющая группа, никаких системных сообщений в клиентских чатах, данные в Studio DB, Memoh как мозг, не как БД.
