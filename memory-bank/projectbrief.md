# Project brief

**pb-memoh-studio** — репозиторий студии: upstream **Memoh** как агентное ядро + **Studio Layer** на Python (FastAPI, Celery, Postgres/pgvector, Redis) для Telegram-операций студии (архив, сводки, SLA, RAG, проекты, правила). Снаружи один Telegram-бот.

Git: `upstream` = memohai/Memoh, `origin` = pbweb-studio/pb-memoh-studio, ветка `pb-studio/main`.
